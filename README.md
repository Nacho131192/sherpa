# SHERPA PROGRAMING — Web

Proyecto web del box de CrossFit SHERPA PROGRAMING (CrossFit, entrenamiento personal y programa Mamá Sherpa: embarazo, hipnoparto y postparto).

## Estado

- **Dirección elegida: A · Cumbre** (fondo oscuro, editorial, numeración por altitud).
- Las opciones B (Expedición) y C (Altitud) se conservan como referencia.

## Estructura

```
maquetas/
  Main.dc.html          Maqueta A · Cumbre (dirección elegida)
  B-Expedicion.dc.html  Maqueta B · Expedición (referencia)
  C-Altitud.dc.html     Maqueta C · Altitud (referencia)
  canvas.json           Índice del lienzo de diseño (3 artboards)
```

Las maquetas son archivos `.dc.html` del lienzo de diseño de Claude. Son HTML autocontenido con CSS y JavaScript en línea; pueden abrirse en un navegador, aunque la interactividad (horarios, FAQ) depende del motor del lienzo.
